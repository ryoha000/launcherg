# Launcherg 0.4.0 プレリリース

Windows向けのプレリリースです。DMM・DLsite連携をベータ機能として追加しました。

- DMM・DLsiteの購入済み作品をブラウザ拡張から登録できます。
- ダウンロードしたゲームの展開・起動リンク登録に対応しました。失敗した処理は保持し、拡張機能から再試行できます。元のダウンロードファイルは自動削除しません。
- PC内のゲーム探索・照合と画像保存を改善しました。
- 画像とダウンロードしたゲームの保存先を設定できます。
- Tauri 2・Svelte 5へ移行しました。
- スマホからの閲覧・リモート起動・メモ転送を終了しました。

## インストールと更新

MSIを実行してください。旧版から更新する場合は、念のため `%APPDATA%\ryoha.moe\launcherg` をバックアップしてください。既存の作品・お気に入り・プレイ日時を新しいDB形式へ移行します。

設定画面の「DMM・DLsite連携」から「ブラウザ連携を準備・更新」を押し、表示された手順に従ってChromeまたはEdgeへ拡張機能を読み込んでください。Node.js・Rust・管理者権限は連携の準備に不要です。拡張機能の更新後はブラウザの拡張機能画面で再読み込みしてください。

## ベータ版での制約

- DMMは購入済み作品の各ページを表示すると同期します。全ページの自動巡回には対応していません。
- DLsiteは購入一覧を開くと、そのページが使う購入キャッシュまたは一覧APIの応答から同期します。別アカウントのキャッシュは検索せず、同期のための追加API通信も行いません。
- ストアのページ・APIの変更によって連携が動かなくなる場合があります。
- 自動登録は起動可能なEXEまたはショートカットを検出できる作品が対象です。展開に失敗した場合や起動ファイルが見つからない場合は、元ファイルを保持してエラーを表示します。
- ブラウザが停止している間はダウンロードの復旧処理も停止します。再起動後に完了済みダウンロードを確認します。
- URLの期限切れなどで再試行できない場合は、拡張機能で「失敗した処理を解除」し、ストアから開始し直してください。解除してもダウンロード済みファイルは残ります。
- このプレリリースは既存の自動更新先に配信しません。

## リリース担当者向け

`task check` と `task build:release` で確認できます。ローカルで署名キーがない場合は検証用MSIを生成します。`node scripts/native-host-smoke.mjs` は一時的なデータフォルダで実際のNative Hostを検証します。

`task check:browser-extension:auto-sync` はローカルの模擬サイトを開くだけで、拡張・実際のNative Messaging・隔離DBまでの自動同期を検証します。DLsiteのv4 POST・v3 XHR・通信しないキャッシュ表示・購入キャッシュ更新と、DMMのfetch・XHRを確認します。厳しいCSP下で動作し、再読み込みでも重複登録せず、別アカウントのキャッシュを取り込まないことを確認します。DLsiteの現行作品URLと遅れて表示されるZIPリンクから、実際のChromeダウンロード・Native Hostによる展開と登録まで検証します。手動同期は使用せず、CIでも実行します。

実機の停止箇所は `task diagnose:browser -- --store dlsite`（DMMは `--store dmm`）で確認できます。拡張の登録状態・DB件数・自動同期の各段階を読み取り専用で表示します。進捗ログは `%APPDATA%\ryoha.moe\launcherg\diagnostics\browser-sync.jsonl` に最大1 MiBと前回分1 MiBを保存します。購入一覧の本文・Cookie・認証ヘッダーは記録しません。`trigger: auto` の `sync_finished` とDB反映をリリース確認に使い、手動同期の成功で代用しません。

GitHub Actionsはタグとリポジトリ内のバージョンの一致を検証し、MSI・更新用署名付きZIP・拡張ZIPを作成します。署名はTauriの更新検証用で、WindowsのAuthenticode署名ではありません。既存の `TAURI_PRIVATE_KEY` / `TAURI_KEY_PASSWORD` シークレットを新しいTauri環境変数へ対応付けています。新名のシークレットがある場合はそちらを優先します。

`release/**` ブランチまたは手動実行では成果物のみを作成します。`0.4.0` タグでは下書きのプレリリースを作成します。公開は下書きと検証結果を確認してから行ってください。既存の `.tauri-updater.json` は自動で変更しません。
